# pair-wise-yf-58 功能开关与依赖联动发布控制台

## 源提示词摘要
运营逐个放开关，互相依赖的开关容易脱节：上游停了下游还在跑，组内放量名额互相挤占。
需要把功能开关、依赖关系和联动发布组接成一个控制台：组内按编号顺序分配总名额，
上游停用/回滚/改规则后依赖方立即失效且整组审批作废，成员写入失败时事务回滚并按原编号重试，
重试不得重复记审计。

## 技术栈
Vue 3 + TypeScript + Vite + Ant Design Vue + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- **功能开关**：规则组合（地区/版本/登录）、放量调整、模拟命中、单独启用（上游必须全部生效）、紧急停用、回滚。
- **依赖关系图**：可多选上游（自动拒绝依赖环）；上游停用、回滚或规则改动后，
  全部直接与传递下游立即标记「联动失效」并关闭，界面展示失效来源事件。
- **联动发布组**：组总名额 + 有序成员（编号可上下调整）；严格按编号顺序依次占用名额，
  一旦某成员要不下剩余名额，它及后续成员全部留在「待放行」（不可插队），并逐个列出占位者。
- **整组审批**：产品 + 研发双审批才能启动；成员/顺序/名额任一变更、组内成员被依赖联动失效、
  或已发布组成员的上游出问题，已有审批一律整组作废。
- **事务式发布**：按编号顺序逐个写入配置中心（`writeMember` 模拟 200ms 远程写入）。
  任一成员写入失败 → 已写入成员按启动前快照精确恢复，未写入成员本就未动；
  组进入「待重试」，编号完全保留，一键按原编号重试。
- **审计幂等**：一次发布会话（含其全部重试）共用幂等键 `launch:<组>:<会话号>`，
  每次尝试只追加合并到同一条审计记录，绝不重复记账；结构变更后才开启新会话。
- 故障注入开关可模拟任意成员写入失败；离线提示、Zod 校验、localStorage 持久化、一键重置演示数据。

## 关键实现位置
- 顺序名额分配（`allocate`）、传递下游（`downstreamOf`）、成环检测（`wouldCycle`）、
  有效性判定（`isEffective`）：`src/stores/flags.ts` 顶部纯函数，可独立测试。
- 级联失效与组审批作废：`cascadeInvalidate`。
- 事务发布 / 快照回滚 / 原编号重试 / 幂等审计：`launchGroup`。
- 自动化验证脚本：`scripts/verify.ts`（27 项断言），运行：
  ```bash
  npx esbuild scripts/verify.ts --bundle --platform=node --format=esm --outfile=/tmp/verify.mjs && node /tmp/verify.mjs
  ```
